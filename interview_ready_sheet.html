4. Key Technical Interview Questions & Answers
Q1: How do you maintain fast rendering when calculating monthly summaries for dozens of customers?
A: Deliveries are stored in a normalized hash map { [date]: { [customerId]: { morning, evening, isHoliday, rate } } } providing $O(1)$ updates. Calculations for daily dashboard metrics and customer month aggregates are memoized with useMemo, eliminating unnecessary recalculations during searches or filter changes.
Q2: Why choose a Local-First architecture rather than a backend database?
A: Milk delivery vendors operate on early morning routes with poor mobile network connectivity. Local-first architecture guarantees 100% offline availability with zero server lag, while JSON backup/restore and CSV exports ensure zero data loss.
Q3: How did you implement thermal slip printing in the browser?
A: I implemented targeted @media print CSS rules that isolate the receipt DOM element, set monospace typography, hide non-printable navigation bars/buttons, and enforce thermal printer dimensions (58mm/80mm) via window.print().
